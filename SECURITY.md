# Security policy

## Supported lines

| Line | Status |
| --- | --- |
| Pre-development documentation on main | Reports about repository content are accepted |
| Released plugin versions | None; no plugin is implemented or supported yet |

The planned plugin is not a sandbox. Messaging and cooperative resource reservations would not, by themselves, authorize actions or isolate processes, files or external applications. No remote-control endpoint is provided by this repository.

## Reporting a concern

Reports can be sent through [GitHub private vulnerability reporting](https://github.com/Yivas/cotilleo-convo-pi/security/advisories/new), which is enabled for this repository. Security-sensitive details must not be posted in public issues or pull requests. If the private form is unavailable, a public issue may request a private contact without disclosing the vulnerability.

A report should identify the affected file or commit, host and operating system when relevant, minimal sanitized reproduction, expected and observed behavior, potential impact and any workaround. No supported release number can be supplied yet; a commit or document link is sufficient.

Credentials, tokens, personal paths, private prompts, conversations, model configuration and data from other sessions must be removed. Tests must not access other people's resources or cause damage. Reporting a concern does not authorize active testing beyond resources the reporter controls.

Yivas will assess the report, request clarification when needed and coordinate any fix or disclosure with the reporter. No response deadline, reward, CVE assignment or embargo is promised.

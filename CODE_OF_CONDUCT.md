# Code of Conduct

Discussion should address the work and allow people to disagree without personal attacks. Useful criticism describes the problem and evidence; participants should respect boundaries, privacy and a request to stop unwanted contact.

Harassment, threats, discriminatory attacks, sexual harassment, doxxing, deliberate disclosure of private information and repeated disruptive posting are not accepted. An agent-generated contribution remains the responsibility of the person submitting it.

These rules apply to this project's issues, pull requests, any project discussion spaces and public representation of the project. They do not grant authority over unrelated communities.

Yivas may remove content, restrict participation, close a thread or block an account according to the severity and repetition of the conduct. Moderation should protect affected people without publishing unnecessary personal details.

Visible abuse can be reported with GitHub's **Report content** control on the relevant content. For private or safety-sensitive reports, [GitHub Support](https://support.github.com/contact) provides a platform reporting channel; no separate confidential maintainer inbox is currently offered. A non-sensitive moderation request can be raised in [issues](https://github.com/Yivas/cotilleo-convo-pi/issues). Private evidence must not be posted there, and vulnerability reporting is not an abuse-report channel. No response deadline or outcome is guaranteed.
